# Changelog

## v0.1.0 - 2026-05-29

- Added a Qt/PySide6 desktop traffic-light widget for Codex status.
- Added red/yellow/green status mapping for thinking, tool execution, waiting, errors, and inactive sessions.
- Added app-server UI event detection to reduce false green states while Codex is thinking.
- Added a settings window for refresh interval, status windows, opacity, always-on-top, expanded text, and light orientation.
- Added vertical and horizontal traffic-light layouts.
- Added Windows launch scripts and PyInstaller release packaging.
